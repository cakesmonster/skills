# 质量动量策略（G策略）

## 适用场景

- 没有现象级事件时的**默认操作**（有现象级事件时用笨韭体系重仓出击）
- 10万级闲钱，3只票等权，月度操作
- 不需要盯盘，一个月看一次

## 选股池

干净池711只（主板，ROE>10，毛利>15，FCF>0，利息覆盖>3）。
数据来源：`sundial/tools/quality_screen.py` + `quality_screen_l2.py`。
缓存：`sundial/tools/.cache_quality/l2_final.parquet`。

## 入场条件（全部满足才买）

1. **3年区间位置 20-40%**
   - 位置 = (现价 - 3年最低) / (3年最高 - 3年最低) × 100
   - 用月线收盘价计算
   - 不买0-20%（可能还在跌），不买40%以上（不够便宜）

2. **近3个月在涨**（ret_3m > 0）
   - 不接飞刀，等趋势确认

3. **股价在12月均线以上**
   - 中期趋势向上

## 仓位

- 10万分3只，每只约3.3万
- 同时最多持有3只
- 没有符合条件的票 → **空仓**（大部分时间应该空仓）

## 出场规则

### 止损（硬规则）
- 买入后跌15% → **无条件卖出**
- 单只最大亏损：3.3万 × 15% = 4950元
- 3只全触发止损 = 亏1.5万（总资产-15%）

### 移动止盈（核心alpha）
- 持有期间涨幅超过30% → 开始跟踪最高点
- 从最高点回落20% → 卖出
- 例：10元买入 → 涨到15元(+50%) → 回落到12元(从15回落20%) → 卖

### 时间止盈
- 持有满6个月，既没触发止损也没触发止盈 → 卖出

## 排序（从符合条件的票里选3只）

机械筛选只管"能不能买"，排序靠：
1. ROE > 15% 优先
2. 毛利 > 30% 优先
3. 有产业事件驱动的优先（笨韭四要素）
4. 位置更低的优先（20%比39%好）

## 回测数据（全历史 2000-2026，10万条样本）

| 指标 | 数值 |
|------|------|
| 胜率 | 46.8%（单笔），65.9%（月度组合） |
| 中位收益/笔 | +1.15万/10万 |
| Sharpe | 0.42 |
| 最长连亏 | 11个月 |
| 滚动1年亏损概率 | 14.0% |
| 滚动1年最差 | -10.2万 |
| 亏>2万概率 | 0.0%（蒙特卡洛） |
| 5%分位（最差） | -1.5万 |

### 关键发现
- **止盈是最大alpha**：单独加止盈，Sharpe从0.33→0.43
- **止损单独用有害**：胜率从53%掉到46%（被洗出去）
- **止损+止盈配合才有效**：止损兜底，止盈锁利
- **按年拆分没意义**：2008亏-75%，2009赚+97%，重要的是穿越周期的总体期望
- **大盘MA200过滤无效**：20-40%位置本身隐含了"市场在恢复"

## 与笨韭体系的关系

| | G策略 | 笨韭 |
|---|---|---|
| 触发 | 机械规则，每月扫 | 现象级事件，一年1-2次 |
| 仓位 | 3只等权 | 可重仓单只 |
| alpha来源 | 均值回归+动量+纪律 | 选对方向 |
| 中位收益 | +1.15万/笔 | 不可测 |
| 适用 | 没有大事件时 | 有产业拐点时 |

## 月度操作清单

1. 每月初运行 `sundial/tools/scan_entry_signals.py`
2. 查看符合条件的票（通常0-5只）
3. 按排序规则选最多3只
4. 挂限价单买入（不追涨，挂在前一日收盘价附近）
5. 设置止损提醒（-15%）
6. 每周末看一次：有没有触发止盈/止损
7. 6个月到期清仓

# 高股息策略（攒股收股息）

## 策略定位

"御龙大师兄六条路"中的第三条：攒股收股息。
- 不依赖股价上涨赚钱，依赖"企业还在赚钱+每年分红"
- 熊市天然抗跌：公路/银行/能源不会因为金融危机就不赚钱
- 股价跌了股息率反而更高，吸引资金抄底 → 跌不深

## 选股池规则

1. **沪深主板**（600/601/603/605/000/001/002/003）
2. **近5个财年中至少3年有现金分红**
3. **平均股息率 ≥ 4%**（股息率 = 当年每股分红 / 当年年末实际股价，不复权）
4. 当前池子约 126-172 只（随年份变化）

## 入场条件

- **3年区间位置 < 40%**
  - 位置 = (现价 - 3年最低) / (3年最高 - 3年最低) × 100
  - 用月线收盘价计算
- 不需要动量确认（回测证明加动量反而变差）
- 不需要MA均线确认（S7加MA12是唯一被熊市淘汰的变体）

## 出场规则

1. **止盈**：持有期内涨超30% → 卖出（实操按最高点的80%估算）
2. **时间止盈**：12个月到期，未触发止盈 → 卖出
3. **不止损**（回测证明加止损-20%后中位数从+26.8%降到-20%，止损是毒药）
4. 分红每年照拿（约4-6%），是收益的确定性底仓

## 仓位

- 3只等权（10万 → 每只3.3万）
- 分散到3只后熊市亏损概率降到0%（26年所有熊市加总模拟）
- 1只集中：波动大，5%分位-20%
- 5只以上：收益被摊薄

## 已知局限（诚实申报）

1. **轻微幸存者偏差**：akshare数据库退市股不完整。但高股息主板股（公路/银行/能源）退市极少，影响有限。
2. **止盈乐观假设**：用了"最高点×0.8"，实操会差一点。
3. **2008年+99%需要你敢在恐慌里买**：信号在股价跌进40%位置时才出现。
4. **最差年份不是亏钱，是不赚钱**（2017: -3.1%, 2023: +0.2%）。代价是时间成本。
5. **股息率陷阱**：单年股息率高可能是股价暴跌导致的。所以要求"连续3年分红+平均股息率"，排除一次性高股息。

## 数据源

- 分红数据：`akshare.stock_fhps_em(date='YYYY1231')` — 全市场，含股息率字段
- 月K数据：腾讯接口 `web.ifzq.gtimg.cn`（前复权+不复权两套）
- 回测脚本：`sundial/tools/backtest_v9_pit_dividend.py`
- 缓存：`sundial/tools/.cache_quality/backtest_v9_pit/`

## 操作节奏

- 每月1号扫描一次池子（等扫描工具建好后）
- 有信号（位置<40%）→ 买入，3只等权
- 持有12个月，中间不看盘
- 涨30% → 卖；12个月到期 → 卖；分红照拿
- 没信号 → 什么都不做

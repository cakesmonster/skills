# 行业筛选方法论：漏斗筛选 + 瓶颈猎手

---

## 一、行业漏斗筛选：从全市场到 3 家

### 漏斗结构

```
第一层：全市场扫描     30-60 家   （活跃度+涨幅+市值前30的并集）
        ↓ 价值投资 5 条硬指标
第二层：粗筛             ≤ 10 家   （5条全部及格 + 护城河★★★以上）
        ↓ 精细分析
第三层：精细分析          ≤ 10 家  （每家 300-500 字结构化分析）
        ↓ 终选
第四层：四大师深度分析     3 家     （每家 800-1200 字）
        ↓
输出：投资建议 + 操作信号 + 仓位建议
```

每层"过滤掉的标的"必须留下淘汰理由，不能黑箱。

### 第一层：全市场扫描

三类并集：
- A类（成交活跃度）：近30天日均成交额行业前列
- B类（涨幅榜）：近30天涨幅前20 + 近90天涨幅前20
- C类（市值锚定）：行业内市值前30

必须覆盖：A股、港股、美股、日韩台欧相关公司。行业占比<30%的"沾边股"标注"非纯正标的"。

### 第二层：5条硬指标粗筛

| # | 指标 | 通过标准 | 放宽条件 |
|---|------|---------|---------|
| 1 | PE估值 | 合理（与历史区间、同业对比） | 高成长可放宽到PEG<1.5 |
| 2 | ROE | >15%或近3年趋势改善 | 重资产行业可放宽 |
| 3 | 经营现金流 | 为正且占净利润>70% | — |
| 4 | 资产负债率 | <60% | 公用事业/电力可放宽至70% |
| 5 | 护城河快评 | ★★★以上 | — |

保留规则：5条全过→保留；4条+1条接近→保留标黄；不足4条→淘汰。目标≤10家。

### 第三层：精细分析模板（每家300-500字）

```
一句话商业模式：卖什么、卖给谁、怎么收钱
财务质量：收入增速/利润增速/毛利率/ROE/现金流 + 关键转折点
护城河深度：主要类型+证据 + 5年后是否还在
主要风险（前3）
估值快评：当前PE/PS + 历史区间 + 同业对比 → 贵/合理/便宜
进入终选？是/否（理由）
```

### 终选3家的组合逻辑

不是按打分排序选前3，而是按"投资组合互补性"：
- 至少1家"高确定性低弹性"（巴菲特型）
- 至少1家"中等确定性中等弹性"（成长型）
- 可选1家"高弹性高风险"（期权型）
- **找不到3家就写2家+1家观察，不凑数**

### 第四层：四大师深度分析

对终选3家执行：
- 段永平视角：生意本质、本分、持续性
- 巴菲特视角：五类护城河打分（★1-5）+ 安全边际
- 芒格视角：前3失败路径 + 最坏情景估值 + 聪明人为什么不买
- 李录视角：文明级还是阶段性？10-20年终局？赢家通吃？

综合推荐度：
```
推荐度：★★★★☆
仓位类型：核心 / 卫星 / 期权 / 观察
建议买入区间：当前价 / 回调N% / 有耐心等待
建议持仓比例：占该主题仓位X%
关键监测指标：逻辑反转的信号是什么
```

## 二、供应链瓶颈猎手

### 核心理念

> 不问"推荐什么股票"，问"如果这个趋势继续扩张，哪一环会先不够用？"

超额收益来源：第一层瓶颈（GPU、HBM、电力）已被充分定价。真正的alpha在**第二层、第三层**——光模块、激光器、InP衬底、SOI晶圆、外延设备、晶圆级测试、IC载板、特殊玻纤等。

### 超级趋势确认标准

| 标准 | 要求 |
|------|------|
| 持续性 | 至少3-5年确定性增长 |
| 物理性 | 需要实际硬件/材料/设备建设（区分"软件升级"和"物理扩建"） |
| 规模性 | 全球资本开支>500亿美元/年 |
| 加速性 | 需求增速>供给扩产速度 |

### 供应链分层拆解

```
Layer 0（终端）：最终产品/服务
Layer 1（核心组件）：已被市场充分关注 ⬆ 定价充分，alpha有限
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
Layer 2（子组件/材料）：关注度低 ⬇ alpha集中区
Layer 3（上游设备/原料）：制造子组件的设备和原材料
Layer 4（基础设施）：电力、冷却、土地、人才、认证
```

### 瓶颈判定6条标准

| # | 标准 | 🔴 | 🟡 | 🟢 |
|---|------|-----|-----|-----|
| 1 | 供给集中度 | ≤2家 | 3-5家 | >5家 |
| 2 | 扩产周期 | >2年 | 1-2年 | <1年 |
| 3 | 替代难度 | 不可替代 | 部分可替代 | 易替代 |
| 4 | 产能利用率 | >90% | 70-90% | <70% |
| 5 | 需求增速 | >50%/年 | 20-50% | <20% |
| 6 | 客户验证周期 | >1年 | 6-12月 | <6月 |

**瓶颈评级**：🔴≥4个=S级（单点故障）| 🔴3个=A级 | 🔴1-2个=B级 | 无🔴=非瓶颈

### 从瓶颈到标的

初筛：已上市 + 瓶颈业务占比>30% + 市值优先<100亿美元 + 日均成交>100万美元

**估值检查（不可跳过）**：

红灯（满足任一条→信号封顶★★）：
- 市值 > TAM的20%
- PS > 30x 且收入增速 < 100%
- 市值 > 5年乐观收入预测的10倍

黄灯（需额外解释）：
- 亏损 + PS > 15x
- PS是同行盈利公司的5倍以上
- PE > 80x

绿灯（加分）：
- PS < 10x 且收入在增长
- PE < 30x 且有护城河

**估值安全边际检验**：以当前市值买入，假设最乐观情景全部兑现，10年后以25x PE退出，年化回报是多少？<10%→不具备安全边际。

### 交叉验证

正向：客户已签约？收入已体现？产品在涨价？产能真紧张？有扩产capex？

反向（芒格式）：
- 聪明人为什么不买？
- 这个瓶颈能被绕过吗？
- 中国/其他玩家能不能很快复制产能？
- 终端需求放缓50%会怎样？
- 管理层有没有在高点增发稀释？

### 信号强度评级

- ★★★★★：多重交叉验证 + 客户已导入 + 收入已体现 + 估值绿灯
- ★★★★：大部分验证通过 + 估值绿灯或黄灯
- ★★★：逻辑成立但部分待验证
- ★★：早期信号，或估值红灯
- ★：纯概念、未验证

### 核心原则

1. 不让AI推荐股票，让AI拆供应链——问题比答案重要
2. 物理优先——只关注需要实际物理产品/材料/设备的环节
3. 第二层、第三层——不追已被充分定价的龙头
4. 交叉验证——每个结论至少2个独立信源
5. 诚实面对不确定性——找不到数据就写"数据不足"
6. 瓶颈有时效性——每个瓶颈都会被解除，关键是判断时间窗口
7. **瓶颈真实≠投资机会**——PS>30x的亏损公司坐在最紧的瓶颈上也不是买点
8. 估值是硬门槛，不可被瓶颈纯正度、信号强度或叙事吸引力覆盖

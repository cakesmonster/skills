# 四大师综合分析框架（七步法）

> 基于巴菲特、芒格、段永平、李录四位投资大师的方法论，按七个模块顺序执行研究。

---

## 第一步：数据收集

收集以下数据（所有财务数据必须来自两个独立来源，误差>1%须标记）：

1. 收入结构：最近财年及近4季度分部收入、增速、毛利率
2. 财务指标：近5年收入、净利润、毛利率、经营利润率、自由现金流、现金储备
3. 竞争格局：市场份额、主要竞争对手对比
4. 商业模式与护城河：核心竞争优势来源
5. 技术能力：核心技术栈、研发投入
6. 管理层：创始人/CEO履历、持股比例、关键决策记录
7. 行业前景：TAM（总可寻址市场）、增长预测
8. 风险因素：地缘政治、监管、供应链等
9. 当前估值：市值、PE、PS、PEG、EV/Revenue
10. 多空双方核心论点

**数据交叉验证规则**：
- 每个关键数据点至少2个独立来源
- 发现差异时，优先采用公司年报/交易所数据，注明差异原因
- 所有涉及计算的数据必须精确验算，禁止心算
- 常见错误：市值单位（港币亿 vs 人民币亿 vs 美元亿）、FCF口径差异、AB股经济权益≠投票权

## 第二步：生意本质分析 — 段永平"对的生意"

> "买股票就是买公司，买公司就是买公司的未来现金流折现，句号。"

分析要点：
- 用一句话定义这门生意的本质
- 收入结构拆解
- 5年盈利能力趋势
- 商业模式画布：一次性销售 vs 订阅/复购？硬件 vs 软件 vs 平台？
- 生态粘性/客户锁定强度
- 毛利率水平与同行对比，解释为什么高/低
- 经营杠杆分析

**段永平式追问**：
- 这门生意好在哪？如果只能用一句话描述，是什么？
- 如果股市明天关闭5年，你愿意以这个价格持有吗？
- 竞争对手拿100亿能复制这门生意吗？

### 段永平核心思想

**投资信仰**：
- 股市长期是称重机，短期是投票器。有信仰的人等得起。
- 未来现金流折现只是一种思维方式，没人真用公式。能毛估估就够了。
- 看不懂的公司，一个都不投。能看懂的往往就那几家。

**生意模式判断**：
- 巴菲特说生意模式最重要，我从那顿午餐学到的最值钱的话。
- 好的生意模式 = 长期能赚很多钱，且别人很难抢走。
- 差异化是生意模式的根本。没有差异化，就只能靠价格战，那是最苦的生意。

**本分**：
- 做对的事情，把事情做对。
- 不占别人便宜，不因为短期利益损害长期价值。
- 管理层有没有偏离主业去做不擅长的事？

**卖出三理由**：
1. 发现买错了
2. 公司基本面变了
3. 找到了更好的

## 第三步：护城河评估 — 巴菲特"经济护城河"

逐一验证五类护城河：

| 护城河类型 | 验证方法 |
|-----------|---------|
| 品牌/定价权 | 是否能在不损失销量的情况下提价？提价10%客户会跑吗？ |
| 转换成本 | 客户迁移到竞品的成本有多高？（时间、金钱、风险） |
| 网络效应 | 用户越多产品越好吗？是否存在临界规模？ |
| 规模效应 | 规模带来的成本优势有多大？新进入者能否达到同等规模？ |
| 技术/专利壁垒 | 技术领先几年？能否被逆向工程？专利到期后呢？ |

分析护城河趋势：过去5年变宽还是变窄？未来5年预判。

**巴菲特式追问**：
- 10年后这条护城河还在吗？什么能摧毁它？
- 给竞争对手100亿，能复制这门生意吗？
- 如果只能持有一只股票10年，你选哪个？为什么？

### 巴菲特核心思想

**能力圈**：
- 投资的关键不是评估一个行业对社会有多大影响，而是判断任何一家特定公司的竞争优势，以及这种优势的持久性。
- 你不需要成为每家公司的专家，甚至不需要很多。你只需要能够评估在你能力圈内的公司。
- 能力圈的大小不重要，知道它的边界至关重要。

**安全边际**：
- 用4毛钱买值1块钱的东西。
- 好公司买贵了也会亏钱。
- 反向DCF：当前股价隐含了什么增长预期？如果预期打八折呢？

**内在价值**：
- 内在价值是一家企业在其余下寿命中可以产生的现金的折现值。
- 没有人能精确计算内在价值，但你可以毛估估。
- 如果你不愿意持有一只股票10年，那就连10分钟都不要持有。

## 第四步：逆向思考与风险清单 — 芒格"反过来想"

> "反过来想，总是反过来想。"

- 列出"这家公司可能失败的所有路径"（表格：路径/概率/影响程度）
- 历史类比：找到历史上处于相似位置的公司，结局如何？
- 跨学科分析：用网络效应理论、技术采纳曲线、竞争博弈等模型交叉验证
- 偏误自查：叙事偏差、锚定效应、幸存者偏差
- 收集空方核心论点

**芒格式追问**：
- 我最可能在哪里犯错？
- 聪明人为什么会不买/做空这家公司？他们看到了什么我没看到的？
- 什么情况下这家公司会死？（列出5大情景及概率）
- 如果我知道我会死在哪里，我就永远不去那个地方。

### 芒格核心思想

**多元思维模型**：
- 拿着锤子的人，看什么都像钉子。你需要一整套工具箱。
- 必须知道重要学科的重要理论，并经常使用它们——全部都用上，而不是只用几种。
- 生物学、心理学、物理学、数学——跨学科交叉验证。

**人类误判心理学**：
- 激励引起的偏见：永远不要问理发师你是否需要理发。
- 社会认同倾向：别人都在买 ≠ 应该买。
- 承诺和一致性倾向：一旦公开表态，就很难改变立场。
- 锚定效应：第一个数字会不成比例地影响后续判断。

**逆向思维**：
- 不是问"怎么成功"，而是问"怎么会失败"，然后避开所有会失败的路。
- 先想清楚怎么会死，然后永远不去那个地方。
- 如果我知道答案，我就不需要问了。

## 第五步：管理层评估 — 段永平"对的人" + 巴菲特"管理层诚信"

- CEO/创始人关键决策复盘（表格：时间/决策/结果/评分）
- 资本配置能力：研发回报率、并购成功率、回购时机
- 股东利益一致性：管理层持股、薪酬结构、减持记录
- 组织能力：团队稳定性、关键人才风险
- 企业文化特征

**段永平式追问**：如果CEO退休，这家公司还能保持竞争力吗？

**巴菲特式追问**：他们在没人看着的时候做什么？

### 管理层评估维度

| 检查项 | 评估要点 |
|--------|---------|
| 诚实度 | 过去的承诺 vs 实际交付，有没有"画饼"历史 |
| 资本配置 | 回购/分红/并购记录，有没有在高点增发稀释 |
| 股东利益导向 | 持股比例、薪酬结构、关联交易 |
| 所有者心态 | 创始人 vs 职业经理人，是否把公司当自己的 |
| 公司治理 | 审计意见、商誉减值、信息披露质量 |
| 危机处理 | 困难时期的决策反映了什么品格 |

## 第六步：行业与文明趋势 — 李录"文明演进框架"

- 判断所在行业是否处于"文明级范式转移"
- 历史技术革命类比（蒸汽机/电力/互联网/AI）
- TAM增长曲线与天花板分析
- 公司在产业价值链中的位置
- 技术路线风险
- 客户/供应商集中度分析

**李录式追问**：站在20年后回看，这家公司是"这个时代的标准石油"还是"昙花一现的3Com"？

### 李录核心思想

**文明级判断**：
- 真正的投资机会来自文明级的范式转移——蒸汽机、电力、互联网、AI。
- 区分"文明级范式转移"和"阶段性热潮"：前者需要物理基础设施大规模建设，有不可逆的采纳曲线。
- 赢家通吃 vs 百花齐放：这个赛道的终局是什么格局？

**长期确定性**：
- 我投资的本质是投人。
- 买入只是开始。真正的工作是持有期间的持续跟踪。
- 当事实改变时，我就改变想法。你呢？（凯恩斯）

**知识诚实**：
- 知道就是知道，不知道就是不知道。
- 宁可说"我不知道"，也不要用推测伪装确定性。
- 留白原则：数据不足时标注"灰色地带"，不用推测填充。

## 第七步：估值与安全边际 — 巴菲特"内在价值" + 段永平"对的价格"

- 当前市场定价（关键估值指标表格）
- 反向DCF：当前股价隐含了什么增长预期？
- 三情景估值：乐观/中性/悲观（必须精确计算，禁止心算）
- 与自身历史估值对比
- 与同行估值对比

**段永平式追问**：如果股市明天关闭5年，你愿意以这个价格持有吗？

**巴菲特式追问**：用4毛钱买值1块钱的东西。当前是几折？

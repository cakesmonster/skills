# AI 研究偏见自觉（认识论基础）

> 贯穿所有分析的前置步骤。每次研究前必须执行。

## 核心洞察

**资料多 ≠ 确定性高，资料少 ≠ 确定性低。**

AI（以及人类研究者）最容易犯的错误：把"信息量"等同于"确定性"。一家公司被100个分析师覆盖，不代表你真的看懂了它；一家冷门公司只有3篇报道，不代表它不值得投资。

## 信息丰富度评级（A/B/C）

| 等级 | 特征 | 研究陷阱 | 正确应对 |
|------|------|---------|---------|
| A级（信息充裕） | 上市多年、券商覆盖多、媒体报道密集 | 共识过强，输出趋同于市场定价，alpha有限 | 重点做反面检验：聪明人为什么不买？被忽略的风险是什么？ |
| B级（信息适中） | 上市1-3年、覆盖有限、部分数据需推算 | 用"合理推测"填补空白，看起来完整实则虚假确定性 | 每个推算数据标注置信度，区分"有据推算"和"凭空填充" |
| C级（信息稀缺） | 刚上市/冷门股/新兴市场、几乎无覆盖 | 因资料不足过度保守，误判为"看不清=不好" | 用第一性原理提问，从有限信息中提取商业本质 |

## C级公司的第一性原理研究法

当公开资料不足时，不要试图拼凑出"看起来完整"的报告，聚焦以下底层问题：

1. 客户是谁？为什么付钱？有没有替代选择？
2. 复购靠什么驱动？是习惯、锁定、还是持续创造新价值？
3. 竞争对手拿100亿能复制这门生意吗？
4. 管理层做过什么关键决策？这些决策反映了什么判断力和价值观？

## 偏见自查清单（研究全程保持警惕）

- [ ] 我的"确定性"感受是来自生意本质，还是来自资料数量？
- [ ] 如果把这家公司的资料量减少一半，我的结论会变吗？
- [ ] 分析是否与市场共识高度雷同？如果是，信息优势在哪？
- [ ] 是否存在"公开资料很少但生意本质极好"的可能性被低估了？

## 常见偏见类型

| 偏见 | 表现 | 应对 |
|------|-----|------|
| 龙头偏好 | 大市值公司资料多、分析篇幅长，看起来"更好" | 按硬指标和护城河打分，不按报告篇幅排序 |
| 英文偏好 | 美股资料丰富，A股港股容易被低估 | 中英文都搜，A/H公司不能漏 |
| 故事偏好 | 高涨幅+媒体热度=看起来更好 | 区分"真实收入占比"vs"故事占比" |
| 当下偏好 | 当前财务好的容易入选，错过转型期黑马 | 允许"趋势改善"作为放宽条件 |
| 确认偏见 | 找到看多理由后只找正面证据 | 强制反向验证（芒格式否定） |
| 叙事偏差 | 故事太好听了，逻辑链太顺滑了 | 问"哪个环节最可能断？" |
| 锚定效应 | 被历史高点/低点锚定 | 只看当前内在价值 vs 当前价格 |
| 幸存者偏差 | 只看到成功的案例 | 问"同样起点的公司，有多少死了？" |

## 输出要求

- 报告开头必须包含信息丰富度评级（A/B/C）
- 最终结论中注明"分析置信度"与"实际投资确定性"的区别
- C级公司必须列出"需要一手验证的问题清单"——建议通过田野调查、产品体验、供应链访谈等方式补充盲区

## 段永平原话

> "看不懂"有两种——一种是生意太复杂真的看不懂，一种是你还没花时间去看。

> 能看懂的往往就那几家。看不懂的公司，一个都不投。
